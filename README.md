# pokemon-SnapCrop

**pokemon-SnapCrop** は、「Pokémon Champions」の対戦映像から自分と相手のパーティを自動で撮影し、表示する対戦補助アプリです。

![自動撮影の表示例](README-images/autosnap.png)

## 公開 URL

[https://suisui-swimmy.github.io/pokemon-SnapCrop/](https://suisui-swimmy.github.io/pokemon-SnapCrop/)

## 推奨環境

- Windows / Google Chrome（Microsoft Edge では動作が重くなることがあります）
- 縦横比 16:9 の映像入力

Switch の `設定` → `テレビ出力` → `画面の大きさを調整` は、`100%` に設定してください。

## 初期設定

1. 公開 URL を開くと、ブラウザから `カメラ` と `マイク` の使用許可を求められるので、`許可` を選びます。許可の確認が表示されない場合や、`許可しない`・`ブロック` を選んだ場合は、次の手順で設定を変更できます。

   - **Google Chrome**：アドレスバー左側の `サイト情報を表示` → `設定` → `権限` で、`カメラ` と `マイク` のスイッチを `オン` にして、ページを再読み込みします。
   - **Microsoft Edge**：アドレスバー左側の `サイト情報を表示` → `サイトの設定` で、`カメラ` と `マイク` を `許可` に設定して、ページを再読み込みします。

2. `映像入力` から映像の入力元を選びます。
3. `音声入力` から音声の入力元を選びます。OBS Virtual Camera は映像のみを出力するため、音声は別の入力元を選んでください。

> [!IMPORTANT]
> `マイク` が許可されていても、`音声` がブロックされていると音声は聞こえません。映像と音声を利用する場合は、ブラウザのサイト設定で `カメラ`・`マイク`・`音声` が許可されているか確認してください。
>
> 各設定の役割は次のとおりです。
>
> - `カメラ`：キャプチャ機器などから映像を取り込みます。
> - `マイク`：キャプチャ機器などから音声を取り込みます。
> - `音声`：取り込んだ音声をスピーカーやイヤホンで再生します。

映像が表示されない場合は `映像を開始` を押してください。接続した機器が一覧に表示されない場合は `一覧更新` を押してください。

## 自動で撮影する

16:9 の映像を選ぶと、自動撮影が有効になります。読み込み画面から選出画面・待機画面へ進むと、自分と相手のパーティを撮影します。次の対戦を検出すると、前の対戦の画像をリセットします。

撮影後は、次の情報も自動で表示します。

- 相手が対戦に出したポケモンを確認できると、相手のパーティ画像に `１`・`２`・`３`・`４` の選出番号が付きます。
- 相手のポケモンの名前を推定できた場合は、選出を確認したときにコマンド入力欄の上にそのポケモンの情報を表示します。名前を確定できない場合は未確定のままにします。
- 相手のポケモンの瀕死を検出すると、パーティ画像の該当する枠を暗く表示します。
- 勝敗を確認できると、`[result] WIN` または `[result] LOSE` を表示します。通信切断など、通常の勝敗演出が出ない場合は判定できません。

自動撮影を止めるには `auto off`、再開するには `auto on` を入力して `Enter` を押します。

撮り逃したときは、パーティが映っている間に `snap` を入力して撮影できます。撮影範囲を調整する場合は、次の「手動で撮影する・撮影範囲を調整する」の手順に従ってください。

## 手動で撮影する・撮影範囲を調整する

コマンドは画面下部のコマンド入力欄に入力し、`Enter` を押して実行します。

1. `映像入力` から入力元を選び、`auto off` で自動撮影を止めます。
2. `edit` を入力し、撮影範囲の枠をドラッグして位置や大きさを調整します。
3. `ready` を入力して調整を終えます。
4. パーティが映っているタイミングで `snap` を入力すると、左右両方を撮影します。

自分側だけ撮り直す場合は `snap my`、相手側だけ撮り直す場合は `snap enemy` を使います。調整後に自動撮影を再開する場合は `auto on` を入力してください。

何も入力せずに `Enter` を押す「空 Enter」は、`ready` の状態で自動撮影が停止しているときに左右両方を撮影します。`Ctrl + Enter` も自動撮影が停止しているときに使えます。自動撮影が有効な間は、誤操作を防ぐため、この2つのショートカットでは撮影しません。`snap` コマンドは自動撮影が有効な間も使えます。

## ポケモンの情報を見る

コマンド入力欄にポケモンの名前を入力して `Enter` を押すと、そのポケモンの情報を表示します。

- 入力中は候補が最大5件表示されます。
- `Tab` / `Shift + Tab` で候補を選び、`Enter` で情報を表示します。
- `Esc` で候補一覧を閉じられます。
- 日本語の変換中は候補一覧を表示しません。
- 自動撮影が有効な間は、相手が対戦に出したポケモンの情報も、名前を推定できた場合に自動で表示されます。

![ポケモン情報の表示例](README-images/pokemon-data-display.gif)

## 選出番号・瀕死表示を直す

選出番号が違う場合は `pick set <選出番号> <枠番号>` で訂正できます。選出番号は1〜4、枠番号は相手のパーティ画像の上から1〜6です。

例えば `pick set 2 5` は、上から5番目のポケモンを「相手が2匹目に出したポケモン」として設定します。上から5番目のポケモンの選出番号だけを消したい場合は `pick clear 5` を使います。

瀕死によって暗くなった表示を解除する場合は `faint reset` を入力します。

## 設定と画像の保存

以下の設定はブラウザに保存されます。

- 撮影範囲の位置と大きさ
- 選択した映像・音声入力
- パーティ画像の表示幅やコマンド入力欄を含むパネルの高さ
- ライトテーマ・ダークテーマの選択（画面右上のアイコンで切り替え）

撮影した画像は、ページを再読み込みすると消えます。試合ログもページを閉じると消えます。調査のためにログや画像を保存する方法は、[診断とログの保存](docs/technical-guide.md#診断とログの保存)にまとめています。

## 困ったときは

| 状況 | 試すこと |
| --- | --- |
| 映像が表示されない・入力機器が見つからない | サイト設定の `カメラ` が許可されているか確認し、`一覧更新` → `映像入力` で入力元を選択 → `映像を開始` の順に試してください。 |
| 映像は表示されるが音声が聞こえない | サイト設定の `マイク` と `音声` が許可されているか確認してください。アプリで選択している `音声入力` や、音量・ミュートの設定も確認してください。 |
| OBS Virtual Camera の音声が聞こえない | OBS Virtual Camera は映像のみを出力します。`音声入力` で別の入力元を選んでください。 |
| 自動撮影されない | 映像の縦横比が 16:9 か、Switch の `画面の大きさを調整` が `100%` かを確認し、`auto on` を入力してください。撮り逃した場合は `snap` で撮影できます。 |
| 撮影範囲がずれている | `edit` で調整し、`ready` で調整を終えてください。初期状態に戻すには `crop reset` を使います。 |
| 相手のポケモンの名前が表示されない | 名前を推定できない場合があります。コマンド入力欄に名前を入力して情報を調べられます。 |

分からないことは、専用の[サポートチャット](https://chatgpt.com/g/g-69e6262f0edc8191b991191368c625c6-snapcrop-sahototiyatuto)で AI に相談できます。
